# ✈️ SkyTutor — PPL Study Buddy

An aviation study app for Private Pilot License (PPL) students. Explains
aviation theory in plain English and quizzes you with questions that adapt
to your weak spots.

## Features

- 📚 **Lessons** — bite-sized theory in simple language (Principles of Flight,
  Air Law, Meteorology, Navigation, Instruments)
- ✅ **Adaptive quiz** — tracks what you get wrong and asks more of it
- 📈 **Progress tracking** — per-topic mastery, saved in your browser
- 🧑‍✈️ **Ask the Tutor** — offline chat that answers aviation questions

## Run it

No installation needed. Open `index.html` in any browser — or visit the
live site published with GitHub Pages.

Everything runs offline; progress is stored locally in your browser.

## Built with

Plain HTML, CSS, and JavaScript — no frameworks. Built from scratch as a
learning project, with Claude as the guide.
